Mac Apple Silicon — Terminal Setup for Genovi

Circular genome map plotting on arm64 (M1 / M2 / M3 / M4) chips

Apple Silicon Genovi Ready Rosetta 2 Bioinformatics

Background

Architecture Note

Apple Silicon (M1–M4) uses arm64 architecture. Some bioinformatics tools like Genovi / Circos were built for x86_64 (Intel/AMD). To bridge this gap, we use Rosetta 2 as an emulation layer.

What We'll Do
  • Install Rosetta 2 for x86_64 emulation
  • Add shell aliases to switch architectures on demand
  • Install Miniconda (x86_64 build) for environment management
  • Install Genovi circular genome plotting tool

Preparation

Before You Begin

Make sure Terminal is not set to open with Rosetta. Follow these steps:

  • Quit Terminal — press ⌘ Q
  • Open Finder → Applications → Utilities
  • Right-click on the Terminal icon → Get Info
  • Ensure "Open using Rosetta" is unchecked

Installation Steps

1

Install Rosetta 2

Open Terminal and run the following command to install Rosetta:

Terminal 
softwareupdate --install-rosetta --agree-to-license
2

Edit Shell Script — Add Architecture Aliases

Open your .zshrc file and add the switching aliases:

Step 2a — Open config file
nano ~/.zshrc
Step 2b — Paste these aliases
# Architecture switching aliases
alias arm="env /usr/bin/arch -arm64 /bin/zsh --login"
alias intel="env /usr/bin/arch -x86_64 /bin/zsh --login"
Step 2c — Save and reload
# Save with: Ctrl+X → Y → Enter
source ~/.zshrc
Test the aliases

Switch to x86_64: type intel  |  Switch back to arm64: type arm

3

Install Miniconda (x86_64)

Switch to x86_64 first, then download and install the Intel build of Miniconda:

Step 3a — Switch to x86_64
intel
Step 3b — Download Miniconda x86_64
curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-x86_64.sh
Step 3c — Install to ~/miniconda-x86
bash Miniconda3-latest-MacOSX-x86_64.sh -p ~/miniconda-x86
Step 3d — Reload shell and verify
source ~/.zshrc
# Quit terminal (⌘Q), reopen, then verify:
conda info
4

Install Genovi

Create a dedicated conda environment and install Genovi with its dependencies:

Step 4a — Switch to x86_64 and confirm
intel
arch   # should output: i386
Step 4b — Create genovi environment
conda create -n genovi python=3.7 circos -c bioconda -c conda-forge
Step 4c — Activate and install
conda activate genovi
pip install genovi

Create Circular Plot

Setup Complete!

You can now generate circular genome maps with the following command:

Run Command 
genovi -i NTD75_after.gbk \
       -s draft \
       -t 'Actinacidiphila sp. NTD75' \
       --title_position top \
       --italic_words 1 \
       -cs blossom \
       -te \
       --size

Troubleshooting

Error: Missing Perl Library

If circos --version fails with missing Perl library errors, run these commands:

Fix missing Perl libraries
# Install cpanminus
conda install -n genovi -c conda-forge perl-app-cpanminus

# Install required Perl modules
cpanm Font::TTF::Font Config::General GD GD::Polyline \
      Math::VecStat Math::Bezier SVG Statistics::Basic \
      Readonly Set::IntSpan Text::Format
Expected Versions

Run perl --version → should be v5.32
Run circos --version → should be circos | v 0.69-8 | 15 Jun 2019 | Perl 5.032001

To make the Perl path permanent, add these lines to your ~/.zshrc:

~/.zshrc — Permanent Perl path
# Force conda genovi perl
export PATH=/Users/YOUR_USERNAME/miniconda-x86/envs/genovi/bin:$PATH
export PERL5LIB=/Users/YOUR_USERNAME/miniconda-x86/envs/genovi/lib/perl5/5.32/site_perl:/Users/YOUR_USERNAME/miniconda-x86/envs/genovi/lib/perl5/5.32:$PERL5LIB
source ~/.zshrc
